# Security Policy

## Supported versions

Only the latest commit on `main` is maintained.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**
(<https://github.com/inbyte-me/bokau/security/advisories/new>). You will get a reply as soon as the maintainer can look at it.

Never include real credentials or personal data in a report.
